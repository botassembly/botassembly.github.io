# BotAssembly

> Open source tools for building AI agents

Build production-ready AI agents with composable, well-tested tools. Each project solves one problem well and integrates cleanly with the others.

## The Stack

```
┌─────────────────────────────────────────────────────┐
│                   BA Workflows                       │
│         Define multi-step agent workflows            │
├─────────────────────────────────────────────────────┤
│         Pyxies           │         PureFN           │
│    Specialized loops     │   Deterministic state    │
├──────────────────────────┼──────────────────────────┤
│   innerloop   │    jn    │       slimschema         │
│  Agent loops  │   ETL    │        Schemas           │
└───────────────┴──────────┴──────────────────────────┘
```
